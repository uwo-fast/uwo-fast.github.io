FAST is Professor Joshua M. Pearce's research group at Western University in London,
Ontario. We design low-cost, open-source hardware and release it under free and
open-source licences, so that others can build it, repair it and adapt it. Each
project below is a working repository on [GitHub](https://github.com/uwo-fast), and
its page here is rendered from that repository's own documentation.
